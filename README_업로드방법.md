# 맘풀고 갤러리 관리자 페이지 적용 방법

이 폴더에는 GitHub 저장소 `yongfafa0218-ops/card-gallery`의 루트에 올릴 **세 파일**이 들어 있습니다. 기존 이미지 파일과 폴더는 건드리지 않습니다.

| 파일 | GitHub에서 할 일 | 역할 |
|---|---|---|
| `index.html` | 기존 파일을 **교체** | 방문자용 공개 갤러리입니다. 업로드창이 없어지고, 카테고리 필터와 `카드 관리` 버튼이 생깁니다. |
| `admin.html` | 새 파일로 **추가** | 이미지를 올리고, 카테고리를 이동하고, 카드를 삭제하는 관리자 페이지입니다. |
| `gallery-data.json` | 새 파일로 **추가** | 카드 이름과 카테고리를 저장하는 목록 파일입니다. |

## 업로드 순서

먼저 GitHub 저장소의 기존 `index.html`은 그대로 두고 백업해 두세요. 그 다음 이 파일의 `index.html`로 기존 파일을 교체합니다. 이어서 `admin.html`과 `gallery-data.json`을 저장소의 **최상위 폴더**에 추가하면 됩니다. `Season`, `sky`, 그리고 현재 이미지 파일들은 그대로 유지합니다.

세 파일을 GitHub `main` 브랜치에 반영하면 Netlify가 자동으로 새 버전을 배포합니다. 배포가 끝나면 다음 두 주소를 확인하세요.

| 주소 | 확인할 내용 |
|---|---|
| `https://gallery.mampulgo.com/` | 업로드창 없이 카드, 카테고리 버튼, `카드 관리` 버튼이 보이는지 확인합니다. |
| `https://gallery.mampulgo.com/admin.html` | 파일 선택, 카드 이름, 카테고리 선택, 업로드 버튼, 카드별 `이동`과 `삭제` 버튼이 보이는지 확인합니다. |

## 처음 사용할 때

관리자 페이지에서 업로드·이동·삭제를 처음 실행할 때만 GitHub 토큰 입력창이 열릴 수 있습니다. 기존 갤러리에서 이미 사용한 브라우저라면 저장돼 있던 `gh_token`을 그대로 사용하므로 다시 입력할 필요가 없습니다. 새 브라우저에서는 현재 사용하던 것과 같은 GitHub 토큰을 입력하면 됩니다.

관리자 페이지에서 올린 새 파일은 GitHub 저장소의 `media` 폴더에 자동으로 저장됩니다. 카테고리 이동은 이미지 URL을 바꾸지 않고 `gallery-data.json`의 분류만 바꾸므로 카드 메이커의 기존 PNG 저장 흐름에는 영향을 주지 않습니다.

> **주의:** 관리자 페이지의 `삭제` 버튼은 GitHub 이미지 파일과 카드 목록을 함께 삭제합니다. 필요할 수 있는 이미지는 삭제하기 전에 PC에 따로 보관하세요.
